B2B Developer API

Integrate questionnaire automation directly into your customer portal, CRM, or Slack bots. Clients can send questions programmatically and receive compliant, formatted answers.

POST /api/rfp/answer-single cURL Example 
curl -X POST "http://localhost:8000/api/rfp/answer-single" \
     -H "Content-Type: application/json" \
     -d '{
       "question": "What encryption standard is used for data at rest and in transit?",
       "section": "Security"
     }'
Python Integration FastAPI / requests 
import requests

url = "http://localhost:8000/api/rfp/answer-single"
payload = {
    "question": "Do you support SAML 2.0 Single Sign-On (SSO)?",
    "section": "Authentication"
}

response = requests.post(url, json=payload)
data = response.json()

print("Answer:", data["answer"])
print("Confidence:", data["confidence"])
print("Evidence:", data["sources"])
